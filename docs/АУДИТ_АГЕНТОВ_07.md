## Как читать

Коды состояний — как в §0.1 документа: AS-IS `FULL / PARTIAL / ABSENT / BROKEN / UNKNOWN / NA`;
приёмка `PASS / FAIL / NOT_RUN / NA`. `PASS` стоит только там, где назван выполненный тест. Отсутствие теста —
`NOT_RUN`, а не «реализовано». Строки, исправленные в этой работе, помечены **⟶ FIXED** и ссылкой на GAP.

Тесты гоняются из `tests/`: `py -m unittest <модуль>`; полный набор — `py -m unittest discover -s . -p "test_*.py"`.
