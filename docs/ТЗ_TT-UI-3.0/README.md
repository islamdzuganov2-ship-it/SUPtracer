# SUPtracer / TaskTreker — Dashboard 3.0

**Материалы для согласования дизайна и передачи ТЗ разработчику.**

## Главные файлы

- `TaskTreker_Dashboard_3_0_TZ.md` — подробное самостоятельное техническое задание (~7 тыс. слов): видеоанализ, реальный аудит репозитория, структура экранов, 22 блока исходного payload, библиотека типов графиков, архитектура, изменения по файлам, безопасность, perf, rollout и 67 проверок.
- `TaskTreker_Dashboard_3_0_Concept.html` — самодостаточный **интерактивный** концепт без зависимостей. Открывайте локально двойным щелчком в браузере. Темы, страницы, подбор фильтров, hover-подсказки, открытие записи, увеличение графика, Bento resize/reorder и демонстрационные варианты AI mode работают без сервера.
- `TaskTreker_Dashboard_3_0_Checklist.md` — 67 пунктов проверки, ни один не отмечен выполненным.
- `previews/Dashboard_3_0_Dark_Preview.png`, `previews/Dashboard_3_0_Light_Preview.png`, `previews/Dashboard_3_0_Flow_Preview.png`, `previews/Dashboard_3_0_Agents_Preview.png`, `previews/Dashboard_3_0_Economics_Preview.png`, `previews/Dashboard_3_0_Builder_Preview.png`, `previews/Dashboard_3_0_Security_Preview.png`, `previews/Dashboard_3_0_Mobile_Preview.png` — проверенные браузером изображения разных экранов.
- `previews/Dashboard_3_0_Contact_Sheet.jpg` — четыре изображения для быстрого сравнения направлений дизайна.

## Ограничения

**Все числовые данные в HTML — синтетические.** Прототип не соединён с SUPtracer/TaskTreker, ничего в GitHub не изменено, функций обновления реальных задач в нём нет. Он предназначен для утверждения визуала и взаимодействий.

**Реальная исходная версия** на момент анализа 08.11.2026: ветка `main` commit `dad412c014bc67887909d56b026a402d1328ea55`, доступна также `release/arch-p0`; `разработка` и `тестирование` не обнаружены. ТЗ требует повторной проверки HEAD до реализации.

**Просмотренные референсы:** четыре MP4 от пользователя. Их решения использованы как источник принципов тёмного аналитического интерфейса, стеклянной глубины, hover-to-expand и адаптивного Bento-конструктора. Веб-панель и её данные созданы самостоятельно и не являются копией дизайна роликов.

## Проверка концепта

Проведён smoke через Chromium/Playwright на разметке локального HTML: открытие 10 основных страниц + builder, переключение темы, hover, раскрытие записи, увеличение диаграммы, фильтры, изменение размера плитки, мобильная ширина 390 px, отсутствие ошибок JS и глобального горизонтального скролла на мобильном. Эти проверки подтверждают только **UI-концепт**. Реальная полная регрессия TaskTreker и сохранность его пользовательских данных ещё не проверялись.
