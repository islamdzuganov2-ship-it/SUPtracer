## Как читать

Статусы реализации: `FULL / PARTIAL / ABSENT / NA`. Статусы приёмки: `PASS / FAIL / NOT_RUN / NA`.

- `PASS` стоит только там, где назван выполненный тест.
- Если теста нет, статус `NOT_RUN`, даже когда код по построению «должен» работать.
- `NA` — пункт не применим в P0, потому что относится к функции P1, которой ещё нет. Например, трассы OTel.

Все тесты модуля гоняются из `tests/`:

```
py -m unittest test_arch_e0 test_arch_model test_arch_collect test_arch_static test_arch_process
```

Это 72 теста. Вместе с `test_serve` и `test_tt3_flags` — 93, все OK. Полный набор проекта
прогоняет `pm.py check`: на `0f954e4` exit 0.
